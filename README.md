# 🍴 Food-Ordering-Project – A Simple Food Ordering Web App

![Platform](https://img.shields.io/badge/Platform-Web-blue.svg)
![Tech](https://img.shields.io/badge/Frontend-HTML%20%7C%20CSS-orange.svg)
![License](https://img.shields.io/badge/License-MIT-lightgrey.svg)

**Food-Ordering-Project** is a static web application built using HTML and CSS. It features a clean and minimalistic design to showcase a variety of food items such as Chicken Teriyaki, Chezewan Noodles, Pancakes, and Pasta. The app includes a contact form for user inquiries and is hosted on GitHub Pages, providing a straightforward food browsing experience.

---

## 🚀 Features

### 🏠 Home Page
- Acts as the main landing page displaying a variety of food items.  
- Provides navigation to other sections like Recipe and Contact.

### 🍗 Food Item Listings
- Displays food items with images and basic descriptions.  
- Includes an "Order Now" button for each item (static, for demo purposes).

### 📞 Contact Section
- Contains a simple contact form for users to submit their name, age, and email.  
- Allows users to reach out for inquiries or feedback.

---

## 🛠️ Tech Stack

- **Frontend**: HTML, CSS  
- **Hosting**: GitHub Pages

## 🧪 Installation & Setup

### 📋 Prerequisites
- A modern web browser (e.g., Chrome, Firefox)

### 🧑‍💻 Steps
 
1. **Clone the repository**
   ```bash
   git clone https://github.com/Preveen369/food-ordering-project.git
   cd food-ordering-project
   ```

2. **Open the app**
   - Open `index.html` in your web browser to view the food ordering app.

🌐 Access the live app at: https://preveen369.github.io/food-ordering-project/
